# Synthetic factor-analysis demo

This demo verifies that the public factor-analysis workflow can run without
access to any restricted study data.

## Privacy and provenance

The demo does not contain or load participant data, fMRI measurements,
stimulus-level responses, semantic embeddings, brain maps, or statistics
estimated from the study dataset. `generate_demo_data.py` creates every value
from an independent Gaussian latent-factor model using the documented seed
`20260902`. The artificial dimensions do not correspond to participants,
stimuli, concepts, voxels, vertices, or anatomical regions.

## Run

From the repository root:

```powershell
python Demo/run_demo.py
```

The command generates a 240 x 60 synthetic matrix, fits a five-factor Varimax
model, checks the output shapes and finite values, and writes the generated
files under `Demo/output/`.

Expected outputs include:

- `Demo/output/input/synthetic_response_matrix.npy`
- `Demo/output/input/synthetic_ground_truth_loadings.npy`
- `Demo/output/input/synthetic_data_metadata.json`
- `Demo/output/results/factor_analysis_results.npz`
- `Demo/output/results/factor_analysis_metadata.json`
- `Demo/output/demo_summary.json`

The output directory is excluded by `.gitignore` because every file is
deterministically regenerated by the scripts. On a typical desktop or laptop,
the demo is expected to complete in substantially less than one minute.
